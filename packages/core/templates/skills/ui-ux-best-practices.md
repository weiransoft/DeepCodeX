# UI/UX Best Practices

前端 UI/UX 最佳实践，确保输出符合可访问性与交互质量标准。

## 可访问性（WCAG AA）

- **对比度**：正常文本 ≥ 4.5:1，大文本 ≥ 3:1
- **图片**：所有 `<img>` 必须有 `alt` 属性
- **表单**：所有 `<input>` 必须有关联的 `<label>`
- **语义化**：使用 `<nav>`/`<main>`/`<article>`/`<section>` 而非通用 `<div>`
- **键盘可达**：所有交互元素必须可通过 Tab 键访问

## 交互质量

- **按钮尺寸**：最小可点击区域 ≥ 44px（Apple HIG）
- **焦点可见性**：`:focus-visible` 必须有明显视觉反馈
- **加载状态**：数据获取时使用 skeleton 或 animate-pulse
- **错误反馈**：表单校验失败时显示明确错误信息
- **确认操作**：删除/清空等破坏性操作必须二次确认

## 布局与响应式

- **元素重叠**：禁止意外重叠（z-index 滥用）
- **文字截断**：长文本使用 `text-overflow: ellipsis`
- **视口溢出**：禁止水平滚动条（表格除外）
- **断点**：mobile-first，768px/1024px/1280px 三档
- **安全区域**：使用 `env(safe-area-inset-*)` 适配刘海屏

## UX 反模式（禁止）

- **强制注册**：禁止未试用就要求注册
- **破坏性操作无确认**：禁止删除无二次确认
- **表单无校验**：禁止提交前不校验
- **无限滚动**：谨慎使用，提供"加载更多"替代
- **自动播放**：禁止音视频自动播放（有声音）

## 输出检查清单

- [ ] 对比度符合 WCAG AA
- [ ] 所有图片有 alt
- [ ] 所有输入框有 label
- [ ] 按钮可点击区域 ≥ 44px
- [ ] 破坏性操作有确认
- [ ] 响应式断点覆盖 mobile/tablet/desktop
