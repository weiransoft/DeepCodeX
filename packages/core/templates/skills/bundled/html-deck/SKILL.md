# HTML Deck Skill

生成自包含、键盘驱动、主题可切换的 HTML 演示文稿。最终交付物为单个 HTML 文件，浏览器打开即可放映，无需服务器或构建工具。

## 1. 适用场景

**适用**：从主题、大纲、文档或 Markdown 生成全新 HTML 演示文稿。
**不适用**：已有 `.pptx` 文件的转换；纯前端网站/应用开发（用 web-dev skill）。

## 2. 文档工作流

开发前检查 `.deepcodex/docs/` 是否已有该 deck 的内容规划文档：
- 已存在规划文档 → 直接进入 Step 1 执行
- 缺失 → 在 `.deepcodex/docs/` 创建 `deck-plan.md`（含幻灯片大纲、主题、视觉资产清单），再执行

规划文档为中间产物，最终交付仅含 HTML 与 `assets/` 目录。

## 3. 工作流（5 步）

**严禁跳过 Step 1-3 直接写 HTML。**

### Step 1: 需求分析
明确每张幻灯片的：标题、角色（封面/目录/正文/章节分隔/结语）、内容摘要、视觉资产类型。规则：
- 每页一个核心信息，无法一句话概括则拆分
- 固定开销：封面 + 目录 + 结语 ≥ 3 页
- 正文 ≥ 6 页时，章节前必须加 `section-divider`
- 通读全部标题应能讲完整故事

### Step 2: 主题选择
从 `assets/themes/` 选择主题，写入 `<link id="theme-link" href="./_shared/themes/NAME.css">`。可用主题见 `references/theme-guide.md`：
- `light` — 极简白，内部汇报、技术评审
- `dark` — 深色夜空，技术分享、长时间观看
- 通过 `<body data-themes="light,dark">` 支持 `T` 键实时切换

### Step 3: 图片获取
仅对需要图片的幻灯片获取资产，使用 `trae-api-cn.mchost.guru` 图片生成 API（详见 `references/image-guidelines.md`）：
- 命名规范：`assets/{name}_{width}x{height}.png`
- 尺寸选择：16:9 背景、4:3 内容区、1:1 头像
- 每个图片槽位独立生成，禁止合并多张图为一个文件
- 数据图表用内联 HTML/CSS 实现，无需预生成图片

### Step 4: HTML 构建
1. 脚手架：`bash ./scripts/new-deck.sh <name> <output-dir>`，生成 `<name>/` 目录含 `<name>.html` + `assets/` + `_shared/`
2. 从 `templates/single-page/` 选取版式，复制 `<section class="slide">` 块替换演示数据
3. 应用主题：`cp assets/themes/<theme>.css <name>/_shared/themes/`
4. 添加动画：`data-anim` 属性（`fade-up` 为安全默认，每页最多 1-2 个动画）
5. 演讲者备注：每个 `.slide` 内加 `<div class="notes">…</div>`
6. 生成图片放入 `assets/`，HTML 内用相对路径引用

**每个 HTML 文件首行必须为 `<!-- Generated by DeepCodeX -->`。**

### Step 5: 导航配置
确保 `<body>` 末尾引入 `<script src="./_shared/runtime.js"></script>`，支持键盘导航：
- `→` / `Space` / `Enter`：下一页
- `←`：上一页
- `Home` / `End`：首尾页
- `F`：全屏切换
- `T`：循环主题（需 `data-themes` 属性）
- `O`：幻灯片总览网格
- `ESC`：退出全屏/总览

## 4. 安全规则

- **禁止内联脚本执行**：所有 JS 必须为外部文件（`./_shared/runtime.js`），HTML 内不含 `<script>...</script>` 内联代码
- **禁止外部 CDN**：所有资源本地化，运行时无网络依赖
- **禁止 `eval` / `Function` 构造器**：runtime.js 中不使用动态代码执行
- **CSP 友好**：HTML 不含 `javascript:` 协议，事件绑定通过 `addEventListener`

## 5. 编写规则

- **始终从模板开始**，不从零编写幻灯片
- **使用 tokens 不用字面色**：`color: var(--text-1)` ✓，`color: #111` ✗
- **每页一个 `.slide`**：runtime.js 通过 `.is-active` 控制显隐
- **禁止覆盖 `.slide` 定位**：`base.css` 设 `position: absolute; opacity: 0`，覆盖会破坏翻页系统
- **备注用 `.notes`**：演讲者专属文字绝不放在幻灯片正文中
- **输出语言跟随用户输入语言**

## 6. 验证清单

交付前确认：
- [ ] HTML 首行为 `<!-- Generated by DeepCodeX -->`
- [ ] `<script src="./_shared/runtime.js"></script>` 已引入
- [ ] 主题文件已复制到 `_shared/themes/`
- [ ] 所有图片路径正确（`assets/{name}_{w}x{h}.png`）
- [ ] 无内联 `<script>` 代码块
- [ ] 每个 `.slide` 含 `data-title` 属性
- [ ] 封面、目录、结语三页齐全

## 7. 详细参考

- `references/theme-guide.md` — 主题选择与定制指南
- `references/image-guidelines.md` — 图片获取 API 用法与命名规范
- `templates/single-page/title-content.html` — 单页模板示例

## 8. 文件结构

```
html-deck/
├── SKILL.md
├── scripts/new-deck.sh          (脚手架脚本)
├── assets/
│   ├── base.css                 (tokens + 布局 + 组件，禁止按 deck 修改)
│   ├── runtime.js               (键盘导航 + 主题切换 + 总览)
│   └── themes/
│       ├── light.css            (极简白主题)
│       └── dark.css             (深色夜空主题)
├── templates/
│   └── single-page/
│       └── title-content.html   (标题+内容版式)
└── references/
    ├── theme-guide.md           (主题指南)
    └── image-guidelines.md      (图片获取指南)
```

### Deck 输出结构（由 new-deck.sh 生成）

```
<output-dir>/<name>/
├── <name>.html      (产品 HTML，首行 Generated by DeepCodeX)
├── assets/          (生成的图片)
└── _shared/
    ├── base.css
    ├── runtime.js
    └── themes/<theme>.css
```
