# funnel-bar-chart — 漏斗柱状图

## 场景与意图
- 场景：data-visualization
- 意图：pipeline_conversion_funnel_bar
- 触发：用户意图涉及有序阶段的流失、转化率、漏斗分析、基线转化对比（如"注册漏斗""购买路径""各阶段留存""对比行业基准"）

## 数据形状
- 数据结构：有序阶段数组 + 基线阶段数组；每阶段含名称与数值；阶段顺序固定，不可重排
- 必需字段：
  - `stages`：数组，每项含 `name`（阶段名，2-5 词）、`value`（数值，非负）
  - `baseline`：数组，与 `stages` 等长，每项含 `name`、`value`，作为对比基线
  - `baselineLabel`：字符串，基线来源说明（如"行业基准"）
- 可选字段：
  - `unit`：数值单位（如"用户数""次"），用于提示框与轴标签
  - `baselineConversion`：基线总体转化率百分比，用于头条对比

## 适配要点
- 阶段数 3-6 为宜；超 6 阶段时归并相邻低价值阶段或拆为子漏斗，不堆叠超 6 条
- 柱体居中浮动形成漏斗形态：每条柱以 `[-v/2, +v/2]` 浮动区间绘制，X 轴刻度显示绝对值
- 实际值用 `--chart-series-1` 实心填充；基线值用 `--chart-series-2` 仅描边、透明填充叠加于实际值之后
- 步转化率（相对上一阶段）作为柱上标签；总体转化率（相对首阶段）放头条副标题或提示框
- 基线偏离用紧凑 HTML 条带展示，不用语义色区分普通偏差；仅当用户明确要求状态/风险视图时引入 `--success`/`--danger`
- 单一焦点：流失最大的相邻阶段（在条带中用 `--brand` 边框标记，非彩色填充）

## 降级策略
- 降级原语：`chart-card`（Chart.js 不可用时显示可见 HTML 表格，列：阶段 / 实际 / 步转化 / 基线）
- 降级触发条件：
  - Chart.js CDN 加载失败（`typeof Chart === 'undefined'`）
  - 数据为空或阶段数 < 2
  - canvas 2d 上下文获取失败
- 降级内容在 `<script>` 执行前可见，仅 Chart.js 实例化成功后隐藏
