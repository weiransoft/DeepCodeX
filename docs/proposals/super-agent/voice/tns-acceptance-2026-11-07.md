## 1. 做了什么

| 项 | 内容 |
|---|---|
| 规则实现 | `scripts/voice/text_normalize.py`（唯一权威，纯标准库） |
| 接入 | `mlx_voice_server.py` 的 `apply_tns()`，覆盖 `/tts` 与 `/tts/stream`；新增 `/tts/normalize` 只回规则结果、不加载模型 |
| 打开 | `start.sh` 显式 `export DCX_VOICE_TNS=1`；`/health.versions.tns` 回显 `tns-1.0` |

| 只改声音 | TNS 只改送去合成的文本，界面上展示的原文一个字不动 |

Web 网关重建请求体时不带 `tns`，因此桌面端沿用 sidecar 环境变量默认值；请求级开关仅直连 / 探针可用。

## 2. 三层证据链（不是只看波形自证）

1. **代码层**：每个场景 POST `/tts/normalize`，把**服务端实际跑的规则输出**与本地 `tns-fixtures.json` 的 golden 逐字比对，同时核对规则命中与版本。防止「本地规则对了，sidecar 还加载着旧代码」。
2. **语音层 A/B**：同一段原文分别以 `tns=false` / `tns=true` 请求 `/tts/stream`，量真 TTFA、音频时长、等效单元语速、F0、块内静音，并把 WAV 落盘。分母按**真正念出来的那份文本**算（`speech_units(normalize(text))`），不是界面原文。
3. **ASR 回听**：两路音频都送回 `/asr`，看模型**实际念出了什么**，按 fixtures 的同义关键词组与荒谬模式判定。

15 个场景覆盖：URL/IP/端口、嵌套 JSON、用户主目录与隐藏目录、毫秒单位、百分比、版本号/日期、工单号/电话、环境变量赋值、方括号日志、命令行 `&&`/`--参数`、HTTP 方法与 API 路径、邮箱与 `@`，外加**纯中文 / 中英混排 / 无标点**三个对照组。

阈值在 `tns-thresholds.json`，全部来自既有真机先验（4.92 单元每秒、20% 单块偏差、900ms 静音、0 异常长静音），**没有按本次结果倒推或放宽**。

| 违规 | 实测 | off 组是否同样存在 | 与 TNS 相关 |
|---|---:|---|---|
| `num:xs` 单块 N/A 偏差 | 20.57% | ✅ 完全相同（3.91 u/s） | ❌ 短数字句固有起头偏差 |

也就是说：**7 项里 6 项是 TNS 打开前就存在的历史边界**，TNS 没有把它们变差（`plain` TTFA、RTF、最长静音、欠流格数反而略好）；真正属于本轮能力边界的只有 `code:xl`。

### `code:xl` 根因：有真机逐块证据，不靠推断

on 组 26 块里只有 2 块离群：

```text
#14  15.9单元  2.58s  6.19 u/s  静音   0ms  入口是 GET /api/voice/health，…
#15  21.2单元  5.25s  4.04 u/s  静音 440ms  true, model: {asr, tts}}，超…
```

前端按**原文** 48 字硬切，把 `{ok: true, model: {asr, tts}}` 拦腰切成两半；服务端逐块执行 TNS 时只看到半截 JSON（多余 `}`、裸露 `: ` / `, `），无法还原结构，#15 因此拖出 440ms 静音。

**做了对照实验才下结论**：把全文先规范化（884 字 → 980 字）再按同一套前端分块规则跑一遍，块间语速极差 43.71% → **27.39%**，改善但不达标；而且分块把 `voice` 切成 `v` / `oice`，离群块全是长中英混排串（`stream 的 body 是 text，engine，v…`）。所以「前端也做 TNS」只能部分缓解，还会引入**拉丁词被拦腰切开**的新问题，根子在 48 字字符数切分边界与长英文串的发音量折算。

**本轮没有改前端分块**：这是会改变所有播报行为的架构改动，且实验证明收益不闭环；按红线先如实留边界，不把未验证的推断交给实现。下一步若要根治，应做「词/结构感知的前端切分」并配 A/B 真机，而不是简单把 TS 版规则再实现一遍。

## 8. 诚实边界

- **ASR 会认错字**：「首块」→「手快」、「config.json」→「Config 点 JS」、
  「session.ts」→「session TS」。关键词才用同义组；不能把 ASR 错字当成 TTS 错读。
- **有限规则集，不是文本理解**：未知缩写与新类型非口语文本原样透传。
  `DCX_VOICE_RATE_SERVO` 这类大写下划线标识符仍被模型连读成含混串（真机 ASR：
  `DCXViewWithRadiusEverAll`），本轮没有猜语义、没有把整句翻掉。
- **看到的字 ≠ 听到的字**：百分比、版本号、路径都念成中文读法，这是 TNS 的固有代价；
  每条读法由 `tns-fixtures.json` 锁定，可逐条审计与回退。
- **网关路径没有脚本级端到端验证**：桌面 WebView 用独立 JWT，脚本不代跑；
  sidecar 单点生效由 `/tts/normalize` 与直连真机覆盖，**桌面端真实听感仍需本人确认**。
- F0 / 质心只是音色代理，不等于说话人验证；多次独立自回归生成的起头语调仍带来
  时间窗 F0 起伏，彻底跨段音色克隆需换 base 模型权重，本轮及前几轮均未做。
